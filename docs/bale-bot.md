# راه‌اندازی ربات بله

## متغیرهای محیطی

- `BALE_BOT_TOKEN`: توکن بازو؛ فقط در محیط اجرا.
- `BALE_WEBHOOK_URL`: آدرس HTTPS مسیر `/api/integrations/bale/webhook`.
- `BALE_WEBHOOK_SECRET`: مقدار تصادفی قوی برای اعتبارسنجی webhook.
- `ACCOUNT_LINK_SECRET`: secret مستقل و تصادفی برای hash کدهای اتصال.
- `APP_BASE_URL`: آدرس عمومی برنامه برای لینک داخل اعلان.
- `BALE_API_BASE_URL`: در حالت عادی `https://tapi.bale.ai`.

پس از migration و build، webhook را با `npm run bale:webhook:configure` ثبت کنید و هر دو process تعریف‌شده در PM2 را اجرا کنید.

## جریان اتصال

1. کاربر وارد برنامه می‌شود و `POST /api/notifications/channels/bale` را فراخوانی می‌کند.
2. فرمان برگردانده‌شده (برای مثال `/link 123456`) را برای بازوی بله می‌فرستد.
3. webhook کد را مصرف و کانال را verified می‌کند.
4. وضعیت از `GET /api/notifications/channels/bale` قابل دریافت و قطع اتصال با `DELETE` ممکن است.

کد فقط یک بار نمایش داده می‌شود، ۱۰ دقیقه اعتبار دارد و در دیتابیس فقط hash آن ذخیره می‌شود.

## ساخت تسک

کاربر لینک‌شده و دارای مجوز ایجاد تسک می‌تواند دستور زیر را ارسال کند:

`/newtask @handle | عنوان تسک | 1405/05/20 14:30 | HIGH`

اولویت اختیاری و یکی از `HIGH`، `MEDIUM` یا `LOW` است. تاریخ به وقت تهران تفسیر می‌شود،
فرستنده به‌عنوان تعریف‌کننده ثبت می‌شود و مسئول باید عضو فعال دارای مجموعه باشد.

کاربر می‌تواند بدون تایپ دستور طولانی، از دکمه «➕ ثبت تسک جدید» در `/menu` استفاده کند.
ربات انتخاب مسئول، عنوان، مهلت، اولویت و تأیید نهایی را مرحله‌به‌مرحله دریافت می‌کند.
فرم پس از ۱۵ دقیقه منقضی می‌شود و با دکمه «لغو» هیچ تسکی ذخیره نخواهد شد.

مدیر و مدیر ارشد در منوی اصلی به سه فهرست «تسک‌های باز تیم»، «تسک‌های امروز تیم» و
«عقب‌افتاده‌های تیم» دسترسی دارند. محدوده اعضا از مجموعه‌های تحت مدیریت سرور محاسبه می‌شود
و جزئیات تسک افراد برای مدیر فقط‌خواندنی است.
تسک‌های متوقف از این سه فهرست حذف می‌شوند و فقط در منوی مستقل «تسک‌های متوقف تیم» قرار می‌گیرند.

## استقرار و بازگشت

پیش از restart، `npm run db:migrate:deploy` اجرا شود. سپس web و worker با PM2 restart و health check اجرا شوند. برای rollback می‌توان worker را متوقف کرد؛ جدول‌های افزایشی اعلان روی رفتار اصلی اثر ندارند و نباید در rollback اضطراری حذف شوند.
